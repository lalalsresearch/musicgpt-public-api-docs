title: Create Audio Upload
openapi: 'POST /v2/upload_audio'
---

**Create Audio Upload** reserves a direct-to-S3 upload slot and returns a short-lived presigned POST.

This is step 1 of the upload flow. Describe the file here, upload it straight to S3 with the returned form, then call [`POST /upload_audio/{upload_id}/complete`](/api-documentation/endpoint/upload-audio-complete) (or the [pre-process variant](/api-documentation/endpoint/upload-audio-complete-preprocess) if the file is headed to a remix). Pass the resulting `upload_id` to `POST /MusicAI` or `POST /Remix` (v2).

<Info>
  The returned policy is the enforcement point: it pins the bucket, the exact object key, the content type, and the exact content length. Sending any extra form field — including an ACL — makes S3 reject the upload.
</Info>

---

## Endpoint

```http
POST /api/public/v2/upload_audio
```

---

## Try It Yourself

Use the [Upload Endpoint Explorer](/api-documentation/endpoint/upload-audio-create) to reserve an upload slot with your own file metadata.

## Request Parameters

| Parameter         | Type   | Required | Default | Description                                                                                                                                                    |
| ----------------- | ------ | -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `filename`        | String | Optional | -       | Original filename. Used only as an extension hint; it never becomes part of the stored object key.                                                             |
| `content_type`    | String | Required | -       | Audio MIME type: `audio/mpeg`, `audio/wav`, `audio/ogg`, `audio/flac`, `audio/mp4`, `audio/aac`, `audio/aiff`, `audio/x-ms-wma`, `audio/webm` — or `application/zip` for a dataset archive |
| `size_bytes`      | Integer | Required | -       | Exact size of the file. 1 KB–80 MB for audio, or 1 KB–1 GB for a zip archive. The signed policy pins this exactly.                                             |
| `sha256`          | String | Optional | -       | SHA-256 of the file, hex or base64. When supplied it's pinned into the policy, so S3 itself rejects a body that doesn't match.                                  |
| `conversion_type` | String | Optional | -       | Pipeline hint, accepted for compatibility. Remix acceleration is requested by finishing the upload with the pre-process endpoint, not by declaring it here. Either `REMIX` or unset. |

> **content-type:** application/json

### Dataset archives

Passing `application/zip` reserves a dataset upload instead of a single track. The archive is stored under `datasets/`, may be up to 1 GB, and must contain at least one audio file — `/complete` reads the zip directory (never the audio itself) and rejects an archive that holds none.

<Warning>
  A zip `upload_id` is for the training flow only. `POST /MusicAI` and `POST /Remix` reject it with `422`.
</Warning>

### Uploading to S3

`POST` the returned `fields` as `multipart/form-data` to `upload_url`, with the file as the last part under the field name `file`.

---

## Returns

A `Create_Audio_Upload_Response` object:

| Field                | Type    | Description                                     |
| -------------------- | ------- | ------------------------------------------------ |
| `success`            | Boolean | Whether the upload was reserved                  |
| `message`            | String  | A descriptive status message                     |
| `upload_id`          | String  | Opaque handle for this upload. The only reference you pass back to the API. |
| `upload_url`         | String  | S3 form target                                   |
| `fields`             | Object  | Form fields to send verbatim, before the file part |
| `expires_in_seconds` | Integer | Lifetime of the signed policy                    |

## Sample Request (Python)

```python
import requests

url = "https://api.musicgpt.com/api/public/v2/upload_audio"

headers = {
    "Authorization": "<API_KEY>",
    "Content-Type": "application/json"
}

payload = {
    "filename": "my-track.mp3",
    "content_type": "audio/mpeg",
    "size_bytes": 4213890,
    "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b85"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

## Errors

| Status | Code                   | Meaning                                    |
| ------ | ---------------------- | ------------------------------------------- |
| 400    | `BAD_REQUEST`           | Malformed request                          |
| 422    | `UNPROCESSABLE_CONTENT` | Invalid `content_type`, `size_bytes`, or `sha256` |
| 429    | `TOO_MANY_REQUESTS`     | Rate limit exceeded                        |
| 401    | `UNAUTHORIZED_ACCESS`   | Missing or invalid API key                 |
